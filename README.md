# RISC-V Single-Cycle Processor

## Overview
This project implements a 32-bit Single-Cycle RISC-V Processor using Verilog HDL.

## Features
- RV32I instruction subset
- Single-cycle architecture
- 32-bit datapath
- Register File
- ALU
- Instruction Memory
- Data Memory
- Control Unit
- Branch Unit
